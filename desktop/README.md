# BonBook Studio

برنامهٔ آزمایشی ویندوز برای آماده‌سازی کتاب مصور و صوتی و انتقال یک‌جای آن به BonBook.

## روش کار

۱. «شروع یک کتاب جدید» را بزن؛ فایل PDF، DOCX یا متن را انتخاب کن و یک پوشه برای پروژه بده. شمارهٔ صفحه‌های PDF حفظ می‌شود. صفحه‌بندی Word براساس متن است.

۲. اگر PDF اسکن‌شده است یا حروفش درست استخراج نشده، از «جایگزینی متن آماده» یک متن شماره‌گذاری‌شده یا فایل جداگانهٔ هر صفحه وارد کن. برنامه مدل OCR یا تصویرسازی سنگین روی کامپیوتر نصب نمی‌کند.

۳. در مرورگر داخلی، خودت وارد ChatGPT شو. از «سبک و شخصیت‌ها» سبک را ذخیره کن، فایل متن مرجع را آماده و در چت بارگذاری کن. دستور آغاز کتاب را بفرست و توصیف شخصیت‌های تأییدشده را در دفتر شخصیت‌ها نگه دار.

۴. صفحه را انتخاب کن و «آماده‌کردن دستور در چت» را بزن. برنامه فقط متن دستور را در کادر آماده می‌کند؛ ارسال و دانلود تصویر را خودت انجام می‌دهی. دانلود بعدی به همان شماره‌ای وصل می‌شود که کنار «دانلود بعدی» نشان داده شده است. اگر تصویر قبلی وجود داشته باشد، جایگزینی نیاز به انتخاب صریح دارد.

۵. اگر ورود یا دانلود مرورگر داخلی با حساب تو سازگار نبود، «مرورگر معمولی» را باز کن و تصویر دانلودشده را با «انتخاب تصویر» وارد کن. برنامه رمز، پاسخ‌های چت، کوکی یا توکن حساب را استخراج نمی‌کند.

۶. از تب «صدا و خروجی»، پوشهٔ ویس‌ها را بده. نام‌هایی مثل `10.mp3`، `page-0010.mp3` و `صفحه-۱۰.mp3` به صفحهٔ ۱۰ وصل می‌شوند. قبل از ثبت، شمارش و شماره‌ها نمایش داده می‌شوند. موارد مبهم، تکراری و فایل‌های قبلی خودکار جایگزین نمی‌شوند.

۷. ZIP بساز؛ سپس در پنل BonBook، کتاب مقصد ← ورود فایل ← «بستهٔ کتاب مصور» بارگذاری کن. پیش‌نمایش را ببین و ثبت کن. انتشار کتاب همچنان از مشخصات کتاب انجام می‌شود.

## صدا و زیرنویس

این نسخهٔ ویندوزی فایل صوتی را با شمارهٔ صفحه و تصویر همان صفحه متصل می‌کند. زمان کلمه‌ها را حدس نمی‌زند. ویس‌های بدون زمان‌بندی می‌توانند بعد از ورود، در صف موتور تشخیص گفتار خودِ BonBook قرار بگیرند. اگر پروژه زمان‌بندی واقعی داشته باشد، همان مقادیر در بسته حفظ می‌شوند.

## محدودیت نسخهٔ آزمایشی

- ویندوز ۱۰ یا جدیدتر، نسخهٔ ۶۴ بیتی؛ فایل نصب امضای دیجیتال تجاری ندارد.
- ورود ChatGPT و تولید تصویر وابسته به امکانات و سهمیهٔ حساب خودت است. دریافت خروجی با دانلودِ کاربر انجام می‌شود و API تصویر فراخوانی نمی‌شود.
- هر فایل تصویر یا صوت تا ۳۰ مگابایت، بسته تا یک گیگابایت، حداکثر ۲۰۰۰ صفحه.
- برنامه پوشهٔ پروژه را نگه می‌دارد؛ ZIP فقط فایل‌های متصل به صفحه‌ها را شامل می‌شود، نه نشست مرورگر یا حساب کاربری.

## اجرای توسعه و ساخت نصب‌کننده

در ریشهٔ مخزن:

```powershell
npm ci --prefix desktop
npm test --prefix desktop
npm run dist --prefix desktop
```

نصب‌کننده و نسخهٔ بدون نصب در پوشهٔ نادیده‌گرفته‌شدهٔ `build/desktop` ساخته می‌شوند. برای اجرای توسعه، ابتدا فونت‌های پوشهٔ `client/public/fonts` را به `desktop/ui/fonts` کپی کن و سپس:

```powershell
npm start --prefix desktop
```

فایل فرمت مشترک `shared/illustrated-package.cjs` مرجع اعتبارسنجی هر دو سمت است. بسته شامل `manifest.json` و فایل‌های شماره‌دار زیر `images` و `audio` است؛ اندازه و SHA-256 هر فایل در فهرست ثبت می‌شود.
